# 产品经理方向差异

同一经历针对不同方向需要改变选材和证据重点，而不是简单替换关键词。

## C 端产品

重点：具体用户场景、行为路径、体验问题、需求洞察、增长/留存/转化、灰度与长期影响。

## B 端 / SaaS

重点：业务流程、角色权限、上下游协同、配置与异常、效率、客户交付、可扩展性。不要只列后台页面。

## 平台 / 基建

重点：服务对象、共性问题、抽象边界、资产模型、接入/发现/治理机制、成本与规模化。必须解释为什么要做平台，而不是直接做一个功能。

## 策略 / 增长

重点：目标拆解、基线异常、策略假设、杠杆选择、实验设计、因果判断、分群、灰度、负向指标和复盘。历史对比不能被包装成严格因果。涉及推荐、广告、搜索、增长、定价、补贴、风控、供给分发、数据策略或实验平台时，读取 [strategy-pm.md](strategy-pm.md)。

## AI / Agent

重点：场景为何适合 AI、模型/工具边界、完整任务链、评测、失败分类、降级、反馈回流和业务价值。详细规则见 `ai-pm.md`。

## 路线选择

若候选人能同时证明“平台能力”和“场景应用”，可用两条互补主线；若证据不足，不要为了显得全面强行覆盖所有方向。
